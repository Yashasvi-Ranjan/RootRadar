# RootRadar frontend

React + Vite (JavaScript). Run `npm install`, then `npm run dev` (http://localhost:5173).
The dev server proxies `/api` (including the SSE stream `/api/stream`) to `http://localhost:8080`;
override with `VITE_API_BASE_URL` (see `.env.example`). `npm run build`, `npm run lint`, `npm test`.
